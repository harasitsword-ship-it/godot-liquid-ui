## 🛠️ How It Works (Simple Explanation)

Traditional Godot menus use StyleBoxes — think of these as static wallpaper. You can't bend or animate wallpaper. But godot-liquid-ui draws every element directly onto the screen using code. Each button, panel, and label becomes numbers that can move, stretch, and change color.

This means every single property — width, height, opacity, color, position — can be animated smoothly. Want a button that expands like a drop of water when you hover? Easy. Want a panel that melts and reforms when switching tabs? Done. The secret is that everything is just numbers you can animate.
